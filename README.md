# Hong Kong Residential Property: Total Return Index & Forecasting

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://hk-property-total-return-index.streamlit.app/)

Standard real estate indices skew performance metrics by tracking only capital values, effectively ignoring the compounding power of rental cash flows. This project constructs a true Total Return Index (TRI) for Hong Kong residential properties (1999–2026) and forecasts future returns using Time Series and Machine Learning models.

## 📊 Executive Summary
* **The Problem:** Government-issued Price Indices severely understate the actual accumulated wealth generated by real estate assets. 
* **The Solution:** By merging historical Price Indices with Yield data and applying monthly compounding, this tool generates a Total Return Index across five distinct property classes (Class A to E).
* **Forecasting:** Evaluates a baseline `ARIMA(1,0,0)(1,0,0)[12]` model against a Direct Multi-Step **XGBoost** model. Both models project capital values forward, which are then mathematically recombined with yield assumptions to forecast total future returns.

## ⚙️ Methodology & Financial Engineering

### 1. Data Architecture & Processing
* **Live Data Feed:** Automatically ingests the latest CSV datasets directly from the [Hong Kong Rating and Valuation Department (RVD) open-data portal](https://www.rvd.gov.hk/en/property_market_statistics/index.html).
* **Resilient Fallback:** Engineered with a failover mechanism that seamlessly loads static repository CSVs if the government HTTP request fails.
* **Transformation:** Annualized yields are converted to monthly cash flow equivalents. Capital returns and income returns are calculated independently before being aggregated into a continuous index.

### 2. Time-Series Forecasting & Machine Learning
* **Component Separation:** The models are trained **strictly on the Price Index (log returns)**. Feeding a combined Total Return into the model would introduce artificial smoothing.
* **ARIMA Baseline:** Uses an `ARIMA(1,0,0)(1,0,0)[12]` framework to capture 1-month momentum and 12-month seasonality.
* **XGBoost (Direct Strategy):** Employs an XGBoost model using a Direct Multi-Step forecasting strategy. It takes historical lags and directly targets the future 12-month horizon, overcoming the error-compounding weakness of recursive forecasting.
* **Walk-Forward Validation:** Evaluates models specifically on their 12-month forecasting accuracy across a rolling validation window, dynamically generating RMSE and MAE diagnostics in the UI.
